- メーカー: ミズホ（ユニバーサル）
- 導入時期: 2023-12-18
- 最終更新: 2026-11-22

## スペック要約

- タイプ: スマスロAT（セットループ）
- 純増: BT約2.9枚/G
- コイン持ち: 約31.7G/50枚
- 天井:
  - **BC間**: 最大333G+α → BC当選
  - **BCスルー**: 最大7スルー後の次回BCでBT確定（テーブルにより浅い場合あり。テーブル5以外は最大6スルーで次回BT確定の扱いが多い）
- リセット挙動（設定変更）:
  - ゲーム数天井・BCスルー回数・内部モード／状態・宿怨pt・有利区間 → **再抽選／リセット**
  - 電源OFF/ONは天井・スルー・モード等を**引き継ぐ**
  - 見た目リセット判別は弱い。前日ヤメG・スルーとの突合が必要
  - 設定変更時は**スルー天井が優遇されやすい**（浅いテーブル寄り）とされるが詳細数値は公表薄 → 有力まで
- 設定示唆の有無: あり（弱チェリー確率、BC中撃破人数、終了画面など）

## モード・テーブル（スルー天井の本体）

- 通常モードは **A＜B＜C＜D**。**モードDのBCはBT確定**
- 設定変更時／AT終了時にテーブル（全16種）を抽選し、BC回数ごとに初期モードが並ぶ
- 浅いテーブル例:
  - テーブル16: 1回目からD → 初回BCでBT確定
  - テーブル15: 2回目がD → **1スルー後の次回BCでBT確定**
  - テーブル14: 4回目がD → **3スルー後の次回BCでBT確定**
- チャンス目でモード昇格抽選あり
- **2スルー到達時点でテーブル15・16は否定**（有力）

## 内部状態・ステージ

| 状態 | 示唆ステージ目安 | 備考 |
|------|------------------|------|
| 通常 | 甲賀卍谷 など | — |
| 高確 | 佐屋路 | BC率・BT率アップ |
| 超高確 | 吉田宿 | さらに優遇 |
| 本前兆寄り | 駿府城／極駿府城 | BC+BT本前兆期待 |

- 高確／超高確は概ね15〜35G滞在後に転落。BC当選でリセット
- ∞高確はBCまで継続し得る特殊ルート

## 宿怨ポイント（通称: 穢れ）

| 項目 | 内容 |
|------|------|
| 獲得 | ハマり・連続演出失敗・BCスルー（BT非突入）など不利時の一部 |
| 示唆 | 紫エフェクト（獲得量・蓄積量。小＜中＜大） |
| 天膳BC終了 | サイドランプ／下パネルで蓄積量示唆 |
| MAX確定目安 | 筐体上部→液晶サイド→リールサイド点灯後に**下パネル消灯** |
| 発動 | **MAX後のBC当選** → 宿怨チャレンジ |
| 恩恵 | 突入時点でBT濃厚。成功で**天膳BT＋争忍10人スタート**濃厚。失敗してもBTは確定 |
| その他突入 | エンディング後は必ず宿怨チャレンジ。有利区間リセット後（設定変更以外）も前兆経由で突入し得る |

### 宿怨チャレンジ要点

- 天膳図柄狙え演出最大3回／最大約30G
- ベルナビ100%
- 成功時は導入が天膳・激闘シナリオ＋初回10人寄り → 出玉の主軸

注意: **設定変更時の宿怨ptは再抽選**。リセ直後の「前日穢れ」は引き継がない。リセ後に改めて蓄積した分だけ有効。

## ヤメどころ目安

- 宿怨MAX（下パネル消灯など）なら**次回BC（宿怨チャレンジ）までヤメない**
- 天膳BC終了で蓄積示唆を見てから区切る判断をしてもよい
- スルー浅＋穢れ弱＋高確示唆なしなら、投資と差枚で区切る
- AT後は駿府城スタート等の宿怨チャレンジ示唆を確認
