# スマスロバジリスク絆2 天膳 BLACK EDITION

- メーカー: ミズホ / ユニバーサル
- 導入時期: 2023-12 / 2024-01
- 最終更新: 2026-11-08

## スペック要約

- タイプ: スマスロ AT（セット継続型 BT）
- 純増: 約2.9枚/G
- 天井: BC間333G＋α / BCスルー最大7回後の8回目でBT確定（モードにより6スルー後もあり）
- リセット挙動: 設定変更で天井・内部・宿怨ptなど再抽選。電源OFF→ONは引き継ぎ寄り
- 設定示唆の有無: あり（BC入賞LED、弦之介BC撃破人数、争忍開始画面など）

## ゾーン

| 区間 | 内容 | 備考 |
|------|------|------|
| BC間 | 明確なGゾーンなし | 天井333G＋α狙いが主 |
| 差枚+500〜1000付近 | 有利切れ宿怨チャレンジ狙い | 実践上+1000枚付近で駿府城→宿怨が確認されやすい |
| 13セット到達 | エンディング権利 | 継続漏れ時にエンディング→駿府城→宿怨チャレンジ |

## 設定差が付きやすいポイント

- BC入賞時LED赤＋BT非当選 → 設定4以上（解析サイト）
- 弦之介BC中 撃破666人 / 争忍開始 弦之介＆朧＋鼻歌 → 設定6示唆（解析サイト）
- 単発のイイ感じ演出だけで高設定断定しない

## 実践チェックリスト

- [ ] BT終了時: サブ液晶タッチでボイス確認
- [ ] BT終了後1G: ステージ確認（駿府城なら即ヤメ厳禁）
- [ ] エンディング後: 宿怨チャレンジまで打ち切り
- [ ] 朧BC終了画面: 赤満月＝モードD確定 → BCまで続行
- [ ] 天膳BC終了: サイドLEDで宿怨pt蓄積量確認

## ヤメどころ目安

### 12連〜エンディング周り（重要）

- **12セット継続＝シナリオ完走。13セット到達でエンディング権利**
- 13セット以降、継続抽選漏れでBT終了 → **エンディング発生**
- エンディング後は必ず駿府城経由で**宿怨チャレンジ**へ。**終了画面即ヤメ厳禁**
- 宿怨チャレンジ成功時は天膳BT＋10人状態が期待できる（失敗でも通常BTへ）

### 通常のヤメ時

- BC終了後: 状態確認して数G様子見 → ヤメ可
- BT終了後: ボイス＋1Gステージ確認 → デフォルト＆通常寄りならヤメ可
- **駿府城スタート / 「今が積年の恨みを晴らすときじゃ」** → 宿怨チャレンジ濃厚。絶対続行
- 上位テーブル示唆ボイス（旅/宴の支度が整っております 等）→ BC〜2回以内のBT期待。続行寄り
- 天井近い / スルー深い / 宿怨pt大量示唆 → 深追いしすぎ注意しつつ様子見
