# スマスロ ミリオンゴッド-神々の軌跡-

- メーカー: ミズホ（ユニバーサル系）
- 導入時期: 2026年4月
- 最終更新: 2026-08-09

## スペック要約

- タイプ: スマスロAT（GG＝ゴッドゲーム）
- 純増: 約7.0枚/G（1セット50G・平均約350枚目安）
- 天井: **GG間 最大1480G＋α**
- リセット挙動: 天井を510 / 1000 / 1480Gに振り分け再抽選
- 設定示唆の有無: あり（ユニバプレート＝トロフィー系）

## 天井（要点）

| 条件 | G数 | 恩恵 |

## 狙い目目安（媒体・設定1想定）

- 通常（等価）: **650〜670G〜**（媒体により350G〜プラス表記もあり）
- 5.6枚系: **820G〜**前後
- リセット判別できる朝一: **150〜270G〜**が現実的な帯（媒体差あり）

## ヤメどころ目安

- GG終了後: **G-ZONE抜け＋約32G**の引き戻し（Z-ZONE抽選）を見てからヤメ判断
- 通常画面に戻っても32Gは内部抽選継続、との解析あり
- **ガイアステージ滞在中は転落まで続行**（ヤメ候補にしない）

## ガイアステージ（実践要点）

- 役割: **GG超高確率状態**（通常モードとは別系統）
- 移行: **ガイアベル（右1stナビ）の規定回数到達時の一部**
- 保障: **9G**（3G以下で加算抽選あり。消化後はハズレで転落抽選）

### 移行の裏（ガイアモード）

| ガイアモード | 規定到達時のステージ移行率 |
|-------------|---------------------------|
| 低確 | 約10.2% |
| 通常 | 約30.1% |
| 天国 | 約66.8% |

- 天国は規定回数 **3回以内濃厚**（振り分け上ほぼ1〜3回）
- ガイアモードはGG当選ではリセットされない（有利区間リセット除く）
- 液晶出目示唆（ガイアベル時）: `0ハサミ+中奇数` / `0V7` / `07V` は天国寄り（有力）
- リールフラッシュ: 台風＝周期到達or本前兆寄り／落雷SP＝ステージ移行or Z本前兆寄り（有力）

### 滞在中の熱さ

| 成立役 | GG当選率 |
|--------|---------|
| 中段黄7 / SP役 | 100%（濃厚） |
| 右上がり黄7 | 62.5% |
| 中段青7 | 50.0% |
| その他（ハズレ・ナビ黄7等） | 1.6% |

- 小役履歴は **1連からGG抽選**（通常は3連〜）。青7/黄7の **5連以上でGG濃厚**
- GG当選時 **Z-ZONE 15.0%（設定1・一律）**
- 演出: 奇数揃い＝GG濃厚／**0揃い＝GG＋Z-ZONE濃厚**
- 雷雨+剣・満月4G継続などはZ寄りチャンス（解析上の可能性〜有力）
