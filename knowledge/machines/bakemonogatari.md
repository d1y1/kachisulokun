## スペック要約

- タイプ: スマスロ直AT（差枚管理）
- 純増: 通常AT（ハッピータイム）約2.7枚/G／上位AT（超ハッピータイム）約5.0枚/G
- コイン持ち: 約31.1G/50枚
- 天井:
  - 通常: AT間最大1000G+α → AT＋倍倍チャンス
  - 設定変更後: 最大600G+α → AT＋倍倍チャンス
- リセット挙動: 設定変更で天井短縮。電源入切は天井引き継ぎ（要確認）
- 設定示唆の有無: あり（終了画面・トロフィー・獲得枚数表示・ボーナス確定画面など）

## ゾーン（規定G数でCZ抽選）

| 区間 | 内容 | 備考 |
|------|------|------|
| **51〜100G** | HIGH滞在濃厚帯 | CZ当選時の解呪連モード移行率約50%。ピンポイント狙い |
| **100G** | 規定GでCZ「解呪ノ儀」抽選 | 設定1で約20%（他設定は要確認）。実戦上は当たりにくい説あり |
| **200G** | 規定GでCZ抽選 | 設定差あり（設定1:10%〜設定6:20%）。高設定ほど優遇 |
| **300G** | 規定GでCZ抽選 | **最厚**。設定1でも約40%、設定6で約50%。ゾーン狙いの本命 |
| AT後〜50G | 引き戻し／枚数引き継ぎ | 獲得枚数が残っていると引き継ぎ。深いAT後はフォロー価値あり |
| 600G | リセ時天井帯 | 設定変更後の短縮天井 |
| 1000G | 通常天井 | AT＋倍倍チャンス |

- 当選時は前兆を経由してCZ告知（各規定G到達から前兆開始）
- CZ契機はレア役（強チェリー・チャンス目など）＋規定Gの二系統
- ゾーン単体は「最優先級」ではなく、チャンスがあれば拾う程度（DMMぱちタウン見解）

## 解呪連モード（関連）

- 種類: ショート＜ミドル＜ロング（平均CZ回数 約2／4／10回）
- LOW／HIGH状態で移行率が変化。50GごとにHIGH移行抽選、HIGHは50G継続
- **51〜100GはHIGH滞在濃厚**
- リール変則始動（右→中→左）で解呪連滞在濃厚、左→中→右でミドルorロング濃厚

## 狙い目（等価・目安）

| 狙い | 目安 | 確度 |
|------|------|------|
| 300Gゾーン | 手前〜到達後の即ヤメ台 | 有力 |
| 200Gゾーン | 同上（設定差も意識） | 可能性 |
| 51〜100G | HIGH濃厚＋解呪連狙い | 可能性 |
| 天井（通常） | **700G〜**エントリー目安 | 有力 |
| 天井（リセ） | 朝一・設定変更濃厚台 | 有力 |
| AT後50G | 枚数引き継ぎ・引き戻し | 状況次第 |

## ヤメどころ目安

- AT終了後は引き戻し／解呪連示唆を確認。非当選＋有利区間リセット確認でヤメ可
- 規定G直後の前兆中は即ヤメしない
- 変則始動・HIGH示唆（キスショット目のフラッシュバック）があるなら続行寄り

## 設定差が付きやすいポイント

- 規定G（特に200G・300G）のCZ当選率
- AT初当たり・AT直撃
- スイカ確率
- AT終了画面／トロフィー／獲得枚数表示

## 実践チェックリスト

- [ ] 現在Gが100／200／300帯か（前兆含む）
- [ ] 51〜100GのHIGH・解呪連示唆（変則始動・フラッシュバック）
- [ ] AT後50Gの引き戻し／枚数引き継ぎの有無
- [ ] 天井までの残りG（通常1000／リセ600）
