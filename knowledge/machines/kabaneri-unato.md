# 甲鉄城のカバネリ 海門決戦（カバネリ2）

- メーカー: Sammy（タイヨーエレック製）
- 導入時期: 2024年
- 最終更新: 2026-08-02

## スペック要約

- タイプ: スマスロAT
- 純増: 約6.0枚/G
- 天井: 996G / 6周期（リセット時596G / 4周期に短縮）
- リセット挙動: 天井596G/4周期に短縮。0Gから期待値+1000円
- 据え置き: 通常天井996G/6周期のまま（短縮なし）。0G開始の期待値はリセットより低い
- 設定示唆の有無: あり（3周期目ボーナス当選率・下段ベル・示唆演出など）
- 機械割: 設定1 97.5% 〜 設定6 114.9%（なな徹等）

## 高設定で機械割が上がる要因

出玉の主軸は「初当たり頻度」と「ST到達・連チャン」。高設定は次が同時に良くなる。

| 要因 | 設定1→6の目安 | 機械割への効き方 | 差の大きさ |
|------|---------------|------------------|------------|
| **3周期目ボーナス当選率** | 18.4%→37.1% | 深いハマり減・初当たり加速 | **最大級（約2倍）** |
| **4周期目ボーナス当選率** | 33.6%→46.9% | 短縮帯での取りこぼし減 | 大 |
| **ボーナス初当たり** | 1/254.2→1/195.1 | AT契機そのものが軽い | 大（約1.3倍） |
| **ST確率** | 1/422.5→1/318.5 | 出玉の本命（ST）到達が増える | 大（約1.3倍） |
| **下段ベル（共通13枚）** | 1/121.1→1/99.1 | コイン持ち・ベース向上 | 中〜大（判別主軸） |
| **CZ当選率** | 高設定優遇（詳細調査中） | 周期到達前の自力初当たり増 | 中（数値未確定） |
| **景之STループ** | 高設定優遇（詳細未公表） | 上位STの連チャン期待 | 中〜大（サンプル少） |
| 駿城中・単チャン目3000pt | 1.2%→2.3% | 駿城→ST昇格のわずかな底上げ | 小（判別向きでない） |

要点:
- **一番効いているのは「3周期目で落ちるか」**。低設定は3周期以降に流れやすく、高設定は1〜2周期＋3周期救済で浅く回る
- ST確率差は初当たり差と同程度。**「当たりやすい」だけでなく「当たりがSTになりやすい」**のが機械割の伸び方
- 下段ベルは出玉そのものよりベース寄与＋サンプルが集まりやすい判別材料
- 1・2周期の期待度はもともと高め（約33%以上）で、設定差の主役は**3〜4周期**側

## 穢れ（黒煙ポイント）

不利時に蓄積する救済ポイント。MAX解放後の次回初当たりで恩恵抽選。

| 解放後の恩恵 | 割合目安 |
|--------------|----------|
| 海門回想（景之ST以上スタート） | 約93.6% |
| 真・景之ST | 約5.6% |
| 裏・景之ST | 約0.8% |

蓄積契機の例: CZ失敗、駿城ボーナス失敗、ST駆け抜け、周期天井到達、有利区間開始時の初期pt など。

示唆（非前兆中が主）:
- 会話（深雪・景之返し）: 通常 / 強 / 極
- 扇子: 白+ハズレ=強、青+ハズレ=極
- ウィンドウSU・黒煙エフェクト大: 蓄積多めに期待
- **強・極が出たら解放（次回初当たり）まで継続優先**

注意: 穢れ自体に公表の設定差は薄い。救済・出玉期待の材料として扱う。

## 据え置き／リセット判別

| 材料 | 据え置き寄り | リセット寄り | 確度 |
|------|--------------|--------------|------|
| 前日最終G ↔ 当日G | ほぼ同じ（宵越し） | 前日高Gなのに当日0G付近 | **有力〜確定寄り** |
| 天井 | 996G／6周期のまま | 596G／4周期に短縮 | 確定（仕様） |
| 朝イチ〜60G | CZ・モード示唆が薄い | 示唆・CZが出やすい印象 | 可能性 |
| 開始G | — | 設定変更時に数Gランダム加算の対策あり | 可能性 |

注意:
- 短縮はリセット以外でも起きる（**ST駆け抜け後・景之ST後**も596G/4周期）→ 短縮＝即リセットではない
- 判別不能なら据え置き想定で立ち回る方が安全（リセット特典を当てにしない）
- 出典: slobase / 1geki 等（2026-07時点）

## 設定差が付きやすいポイント（実践向け）

- **最重要**: 3周期目ボーナス当選（1:18.4% / 6:37.1%）。複数回サンプルで効く
- **主軸カウント**: 下段ベル（1:1/121.1 / 6:1/99.1）。マイスロ非対応→自力カウント。目安3,000Gで1/105前後なら4以上期待
- **合算で見る**: ボーナス初当たり・ST確率（4以上なら初当たり1/214・ST1/357より軽い帯）
- **継続材料**: 景之ループ確認＋他要素が良ければ粘り候補（単独全ツッパ材料ではない）
- 示唆演出（おみくじ・終了画面・ボイス・キャラ紹介・トロフィー等）は別途「アイテムくじ」節参照

## ヤメどころ目安

- 1周期目天国確認後
- CZアイコン確認後
- 景之ST後は**ループ確認必須**（次回も景之STの可能性）
- 穢れ・強/極示唆後は**解放（次回初当たり）までヤメない**

## 注意点

- 300G超えたらカバネポイントのみで周期進行 → 深追い注意
- ポイントはST後も引き継ぐ（有利区間リセット時を除く）
- 差枚マイナス自体は設定・ヤメの根拠にしない（ゾーン・穢れ・短縮を優先）

## アイキャッチ（非前兆中）要点

| アイキャッチ | 示唆の方向 |
|---|---|
| 無名 | 無名CZの規定ptが近い示唆 |
| 生駒 | 生駒CZの規定ptが近い示唆 |
| 景之 | 周期（到達）またはCZ規定ptが近い示唆 |

取り扱い:
- 強示唆ではないため「各1回分だけ」加点。ガセや前兆中は加点しない
- 無名/生駒が同時点灯なら、それぞれ1回分だけ確認して失敗ならヤメ寄り

## サブ液晶「おみくじ」要点

### 輪廻くじ（周期・CZ）

- 二廻以内に好機有 = 2周期目がチャンス
- 二、三の廻に兆し有 = 2・3周期目がチャンス
- 輪廻の果報があらんことを = 当該周期 当選濃厚
- 六根清浄 = 当該周期 EP（エピソード）濃厚

実戦Tips:
- 2周期示唆が出たら「300G帯」まで継続が基本線
- EP当選後は海門回想（=景之ST以上）突入が濃厚帯

### アイテムくじ（設定）

| アイテム | 示唆 | 強さ |
|----------|------|------|
| ツラヌキ筒 | 設定4で出にくい | 弱 |
| **無名の短銃** | **設定3で出にくい** | 弱 |
| 自決袋 | 設定1で出にくい | 弱 |
| 菖蒲の弓 | 高設定示唆 | 中 |
| ミヤマカラスアゲハ | 高設定示唆（強） | 強 |
| 小吉 | 設定2以上濃厚 | 中 |
| 中吉 | 設定4以上濃厚 | 強 |
| 大吉 | 設定6濃厚 | 確定寄り |

注意: 短銃・ツラヌキ・自決袋は「特定設定が出にくい」だけで高設定加点はほぼない。

## サブ液晶背景（ST後の続行判断）

| 背景 | 示唆 | 扱い |
|------|------|------|
| デフォルト | なし | 条件次第でヤメ可 |
| **桜** | 4周期以内EP濃厚（出現周期から数える説あり）。駆け抜け／景之ST後は桜or海門城が必須 | 軽く続行。海門城より弱い |

## キリ番（サブ液晶・設定示唆ではない）

サブ液晶Gがキリ番（30G／100の倍数）到達時にキャラが出ることがある。**終了画面と混同しない。**

| 表示 | 示唆 |
|------|------|
| 侑那・鰍・無名・菖蒲 | デフォルト |
| **寝転び無名** | 当該周期のボーナス期待度（高） |
| **桜の無名** | 当該周期のボーナス期待度（激高） |

## オールスター目（1/7281）

状況で恩恵が変わるプレミア。設定差は薄い（全設定共通）。

| 状況 | 恩恵（有力〜濃厚） |
|------|-------------------|
| 通常時 | 銅藍CZ濃厚 |
| 駿城中 | ST昇格／**裏景之**のチャンス |
| 銅藍CZ中 | 真景之濃厚 |
| ST中 | 超カバネリアタック等 |

## 立ち回りTips（本リポ実践より）

- CZ点灯は「各1回勝負」まで。失敗後に強材料が無ければ深追いしない
- ループ非当選かつ穢れが弱いときは区切る。強/極が残れば次回初当たりまで
- 46枚貸し等価の簡易換算: 投資円 ÷ 21.74 ≒ 必要枚数。差枚で損益把握
- 駿城単体はST期待低め。**駿城中のオールスター**なら昇格まで必須確認
