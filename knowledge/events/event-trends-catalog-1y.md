# イベント傾向カタログ（過去〜1年・スロマップ集計）

- 種別: **living（カタログ）**
- 対象期間の意図: **2025-08-05 〜 2026-08-05（本日基準の過去1年）**
- 最終確認日: **2026-08-05**
- 鮮度期限日: **2026-11-03**
- 鮮度ステータス: **有効**
- 起点: 8/5東スロ神奈川で⭐根拠になったイベント群（`2026-08-05-touslot-kanagawa-star-events.md`）

## 鮮度・読み方

| ルール | 内容 |
|--------|------|
| 使う前 | `鮮度期限日` を確認。切れならスロマップ各URLを再取得して更新 |
| 確度 | 数値はスロマップAIの店全体平均。**最大「有力」**。公式保証ではない |
| 公約なし | クロロ系・必勝本系は媒体が「公約なし」明記 → 数字公約は使わない |
| 期間の穴 | 多くのページ集計開始が **2025年7月〜10月**。厳密1年より短いものあり → 表の「集計開始」を見る |
| 個別living | 詳細手順があるものはそちら優先（赤・極・エンジェルS） |

### 更新手順

1. 下表の各「ソース」URLを開き、実績回数・平均差枚・プラス店％を更新
2. `最終確認日`／`鮮度期限日` を書き換え
3. 大きく傾向が変わったら個別 living も同期

## イベント別・1年分の傾向

### 1. スロパチステーション来店取材(青)

| 項目 | 内容 |
|------|------|
| ソース | https://slo-map.com/media/slopachi-station/slopachi-station-blue-visit |
| 型 | **並び系** |
| 有力型 | スロで**6台並びが複数（8か所以上）**。機種またぎ可。パチは2BOX |
| 確定寄り注意 | 公式「来店に公約なし」とされることが多い。赤と差を付けない店増 |
| 1年の読み | 開催が非常に多い（800回超）。**量は多いが質は演者来店・赤より下**（2026-02コラム: 青は圏外寄り） |
| 立ち回り | 並び検出。⑤の日等との**複合**で格上げ |

### 2. スロット天下無双（必勝本）

| 項目 | 内容 |
|------|------|
| ソース | https://slo-map.com/media/pachislot-hisshobon/pachislot-slot-unrivaled |
| 型 | **複合系** |
| 確定 | 媒体「取材に公約等は一切ない」 |
| 有力型 | 全台系2〜3機種＋**6台並び複数（4か所以上）**。ジャグ高ベース |
| 機種帯 | 喰種・北斗・ヴヴヴ2等が頻出 |
| 1年の読み | 実績厚（270回超）。プラス店約半分 → **外れ店も普通** |
| 立ち回り | 全台候補＋長い並び。店の過去同取材を見る |

## 実践用・優先度の目安（1年データから）

| 優先帯 | イベント | 理由 |
|--------|----------|------|
| 厚め | S級極／CG／エンジェルS | プラス店率・平均が相対的に良い |
| 並び特化 | スロパチ青／鎖／SUPERトリプル | 並びを取れる人向け。店平均は青以外厳し目も |
| 複合定番 | 天下無双／S級赤 | 実績多いが半分前後は外れ店 |
| 注意 | SSヒカル | ジャグ特化＋プラス店低め |
| 薄い | アポカリプス／機種指定1回もの | サンプル不足 |
