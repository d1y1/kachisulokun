- **WIN6GAME** の来店取材イベント名のひとつ
- 色違い（赤／青／虹／極／紫／黒 等）があり、色ごとに傾向が異なる

- 複合系（メインAT＋全台系＋少数台など複数軸）

### メイン5（時期で入替あり）

| 優先して見る機種 | 備考 |
|------------------|------|
| 東京喰種 | メイン帯 |
| ヴヴヴ2 | メイン帯。元住吉は餌日あり → 店知識と併用 |
| **モンキーターンV** | メイン帯 |
| 化物語 | 東リベ等へ入替例あり → 鮮度に注意 |
| 転生2 | メイン帯 |

よく言われる配分イメージ:

- メイン5に **各1台以上「てっぺん」**
- かつ5のうち **1機種は設置の約1/2が上2つ**
- 全台系は **総台数の約4%以上** が上2つ（3台以上設置が前提の言い方）
- **2台以下設置**の約1/5以上が上2つ

元住吉（スロ248台）目安: 全台系ざっくり **約10台分以上**（計算例。保証ではない）

### 青との違い（使い分け）

| 色 | メイン傾向の差（有力） | メモ |
|----|------------------------|------|
| **赤** | 喰種・ヴヴヴ2・モンキー・化物語・転生2 | カバネリは入りにくい |
| **青** | 喰種・ヴヴヴ2・モンキー・転生・**カバネリ** 等 | 4台並び比率など別条件あり |

→ 当日が赤か青かで、カバネリの優先度が変わる。

## 立ち回り（実践用）

1. **店告知／DMMで色名を確定**（ここだけ確定にできる）
2. 赤なら本命帯はメイン5。旧イベ定番（チバ／DU等）は補助
3. 店の餌癖（元住吉のヴヴヴ等）でメイン5をフィルタ
4. 設置台数・争奪・末尾を見て着席
5. 傾向は外れ・見せ球あり → 確定扱いしない
