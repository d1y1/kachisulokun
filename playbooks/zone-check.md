# ゾーン確認プレイブック

実践中にゾーンを確認するときの手順。

## 朝イチ稼働では使わない

**開店直後・朝イチ着席の台選びに、ゾーン残り目安（○○G〜等）を出さない。**

- 朝イチは全台ほぼ同条件スタート。ゾーン狙い・あとづもの前提が無い
- 朝イチの台選びは **機種（イベント／設定期待）・末尾・並び・台数** で切る
- ゾーン表・着席ボーダーは **打っている最中の継続／ヤメ** か、**後ヅモ** のときだけ使う
- リセ短縮の価値は「全台リセなら機種選定の材料」であり、特定台のゾーン選別ではない

## 確認順（実践中・後ヅモ）

1. **現在G** を確定する（曖昧ならユーザーに確認）
2. 機種ファイルのゾーン表を見る（`knowledge/machines/`）
3. 直近のボーナス／CZ終了地点から「どの帯にいるか」を特定
4. 天国・通常・地獄などのモード仮説を立てる
5. 「今打つ理由」または「様子見理由」を1行で言う

## 返答で必ず分けるもの

| ラベル | 意味 |
|--------|------|
| 確定 | スペック上ほぼ疑いようがない |
| 有力 | 状況から濃厚だが確定ではない |
| 可能性 | 候補のひとつ |
| 不明 | 材料不足 |

## よくある失敗

- **朝イチ台選びにゾーン目安を出す**（ユーザー指摘・禁止）
- G数未確認のままゾーン断定
- モードとゾーンを混同
- 設定示唆とゾーンを同一視
